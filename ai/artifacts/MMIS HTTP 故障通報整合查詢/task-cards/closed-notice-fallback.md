## 目標

故障通報管理的預設清單查無指定通報時，切到「所有記錄」重查，仍只接受唯一且完全相符的通報。

## 情境包（Context Pack）

- 相關檔案：`src/mmis_connector/fault_notices/reader.py`、其子類別、對應測試、2026-10-15 錄製 HAR。
- 既有模式：`MaximoEventClient` 傳送 event；既有清單表頭、總筆數及業務鍵驗證；既有其他查詢以選單 event 切所有記錄。
- 假設：首次零筆才需切換，錄製的選單語意值 `useAllRecsQuery_OPTION` 可重用。
- 未知事項：未來 MMIS 可能變更選單控制項或表格欄位。
- 允許變更的檔案：共用通報讀取器及其子類別、相關測試、本卡與驗證報告。
- 不得觸碰：登入、認證設定、寫入流程、原始錄製檔案。
- 情境預算備註：只讀專案地圖、流程、讀取器、相關測試、HAR 中相關 event；略過不相關功能。

## 需求

- 先在故障通報管理直接以通報號查詢。
- 首次零筆才開查詢選單、套用所有記錄、再次過濾。
- 第二次仍零筆維持原錯誤；多筆或不符仍拒絕；完整明細輸出格式維持原樣。

## 驗收標準

- 預設查詢命中時不切換。
- 預設查詢零筆而所有記錄有唯一相符通報時讀到明細。
- 兩次均零筆時回報找不到通報。
- event 序號隨 fallback 遞增。

## 實作備註

- 只讀 HTTP event，重用既有 Session 與 parser。
- 不儲存 HAR、cookie 或 token。

## 驗證契約

- 單元測試：相關通報 reader 測試。
- 整合測試：用指定通報號實際執行 CLI。
- E2E 測試：同整合測試。
- 型別檢查、Lint、Build、螢幕截圖：本 Python CLI 修正不適用。
- 安全性檢查：確認沒有憑證、HAR 或 token 入庫。
