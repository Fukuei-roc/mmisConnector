# 功能規格書

## Metadata

- 功能：自動刪除重複開立的日檢工單，第一階段查詢快照
- 英文名稱：Auto Delete Duplicate Daily Inspection Work Orders
- 狀態：使用者於 2026-11-04 指定第一階段範圍
- 風險等級：高，涉及 MMIS 登入、網路及本機資料庫

## 問題與目標

內部使用者需要先取得所有新竹機務段「執行中未派工」日檢工單，作為後續判定重複及刪除的基礎。

## 功能需求

- 執行 `python -m tools.mmis_development.auto_delete_duplicate_daily_inspection_work_orders`，不帶參數。
- 查詢 MMIS 動力車日檢(1A)，條件為配屬段「新竹機務段」及工作單狀態「執行中未派工」。
- 擷取全部頁面，每筆保留車組/車號、工作單、預計檢修(進廠)日。
- 完整查詢成功後，以 SQLite 交易替換舊快照。每筆另存查詢時間，執行結果預設為空白。
- 印出總筆數。查詢或入庫失敗時不得清掉前一次成功快照。

## 非目標

- 本階段不判定重複、不刪除 MMIS 工單、不修改執行結果。
- 無 UI。

## 驗收標準

- 超過 30 筆時逐頁讀完，筆數須等於 MMIS 顯示總數。
- 重跑及零筆結果會替換舊資料；失敗則保留舊資料。
- 資料庫有指定五欄，指令印出總筆數。

## 安全性與驗證

- 使用既有 MMIS 登入設定，資料庫由 Git 忽略，SQL 值使用參數綁定。
- 用合成跨頁測試及實際 MMIS 指令驗證；無畫面截圖需求。
