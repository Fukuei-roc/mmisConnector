# 自動批次核簽功能規格

## Metadata

- 功能：讀取批次核簽頁面的待簽數量。
- 狀態：依 2026-11-16 使用者指示實作。
- 風險等級：高，涉及副段長帳號及 MMIS 網路存取。

## 問題與目標

使用者需要以副段長帳號登入 MMIS，取得批次核簽頁面 17 種單據的待簽數量，供後續自動化步驟使用。

## 範圍

- 從忽略版控的 `.env` 載入獨立的副段長帳密。
- 使用既有 HTTP session 與 Maximo event 切換至 `ZZ_BCHAPPR`。
- 依頁面頁籤讀取 17 種單據的整數數量，輸出 stdout JSON。
- 若頁面類型或資料不完整，輸出安全的 JSON 錯誤並以非零代碼結束。

## 後續核簽範圍（2026-11-16）

- 進入頁面取得 17 類待簽數後，對目前頁簽重複「全選工單 → 批次核簽 → 是 → 確定」。每輪最多 15 筆。
- 每輪重新讀取頁面，依 MMIS 確認對話框的核簽筆數累計本次簽核量。全部為零時只輸出各類已簽核數 JSON。
- 頁面自動切換到下一個有待簽工單的頁簽，程式不送頁簽 click。
- 缺少控制項、對話框或核簽成功訊號時停止，避免盲目重送。待簽數可能因新工單加入而變動，不能作為本次核簽量。

## 原階段非目標

- 原先讀取數量的階段不執行核簽；後續階段已由使用者授權。
- 不產生結果檔案或修改工單。
- 不新增 MMIS 畫面。

## 資料與驗收

輸入為副段長帳密環境變數。輸出為 17 個中文單據類型到非負整數的 JSON 對應。驗收時須能用副段長帳號取得即時數量，並通過錄製 DOM 的解析測試。

## 安全性

程式不記錄密碼、cookie、CSRF token 或錄製 HAR。HTTP 請求沿用同源限制，帳密只載入程序記憶體。
