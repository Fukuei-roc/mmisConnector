# 功能規格書

## Metadata

- 功能：批次回填最新定期檢修工單至配屬車號總表
- 負責人：MMIS Connector
- 狀態：已實作（2026-10-27 使用者要求實作並追加錯誤後接續處理）
- 風險等級：高（讀取 MMIS，覆寫指定 Excel）

## 問題與目標

使用者要依 Excel 的「車組/車號」查詢最新定期檢修工單，將「檢修級別」、「工作單」、「檢修日期」填回同一列。單列查詢失敗後仍須處理後續車號；重跑時從未完成列繼續。

## 非目標

- 不修改 MMIS 資料。
- 不新增 Excel 欄位或另一份結果檔。
- 不變更既有單車查詢的篩選條件或結果選取規則。
- 不以工作表記錄帳號、密碼、cookie 或查詢錯誤明細。

## 使用者故事

| 故事 | 身為／我想要／以便 | 驗收標準 |
|---|---|---|
| 批次回填 | 身為 MMIS 使用者，我想依車號批次查詢，以便補上三個檢修欄位。 | 成功列寫入 B 至 D 欄，A 欄與其他內容維持原值。 |
| 錯誤後接續 | 身為 MMIS 使用者，我想讓單列錯誤不阻斷整批，並可重跑補查。 | 失敗列保持未完成，後續列繼續；重跑跳過已完成列。 |

## 功能需求

- 預設檔案為 `C:\Users\NMMIS\Downloads\軔管日期統計\配屬車號總表.xlsx`，可指定其他檔案以供驗證。
- 在建立 MMIS session 前檢查檔案存在、為可讀的 `.xlsx`、工作表與 A 至 D 欄標題依序為「車組/車號」、「檢修級別」、「工作單」、「檢修日期」。結構錯誤時不修改檔案，也不連線 MMIS。
- A 欄有值且 B 至 D 欄均已完成的列跳過。其餘列使用同一個 MMIS session 逐列查詢，完整成功才覆寫該列 B 至 D 欄。
- 單列 MMIS 或網路查詢失敗時，重新建立連線並最多嘗試三次。仍失敗則保留該列原狀，記錄列號並繼續。每筆成功後安全替換原活頁簿作為進度點；寫檔失敗時中止，避免報告未保存的成功。
- 指令輸出 JSON 摘要，包含成功、跳過、失敗數與失敗列號。只要有失敗列，結束碼非零。下次執行可續查未完成列。

## 資料與安全性

- 輸入：A 欄車號及既有 `LatestPeriodicInspectionWorkOrderQuery` 的固定篩選條件。
- 輸出：原檔 B 至 D 欄，以及 stdout 的批次摘要。
- 仍使用既有 MMIS 認證機制；輸出與 Excel 不含憑證或 session 資料。
- 寫檔採同資料夾暫存檔加原子替換；操作時須避免另一個程式同時編輯同一活頁簿。

## 驗收與驗證

- 驗證缺檔、錯誤標題、空白車號、查詢重試、單列錯誤後續處理、重跑續查、寫檔失敗及工作單文字儲存。
- 使用暫存 Excel 與假查詢驗證狀態轉移，最後讀回實際 Excel 確認標題、列數、完成及失敗列。
- 此為 CLI 與資料工作，沒有 UI mockup 或截圖需求。
