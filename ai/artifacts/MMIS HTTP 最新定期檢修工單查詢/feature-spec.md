# 功能規格書

## Metadata

- 功能：查詢最新定期檢修工單
- 負責人：MMIS Connector
- 狀態：人工已核准（2026-10-27 使用者直接要求實作）
- 風險等級：高（沿用 MMIS 身分驗證與網路邊界，唯讀）

## 問題與目標

使用者要用一個車組/車號取得符合錄製篩選條件的最新定期檢修工單，免於逐頁比對日期。使用者是有權存取 MMIS 的內部操作人員。

## 非目標

- 不修改 MMIS 資料，不下載或建立查詢結果檔案。
- 不新增正式 `mmis-connector` CLI 子命令或瀏覽器依賴。
- 不查詢工單明細；四個輸出欄位都來自清單。

## 使用者故事與旅程

| 故事 | 身為／我想要／以便 | 驗收標準 |
|---|---|---|
| 最新工單查詢 | 身為 MMIS 使用者，我想輸入車組/車號，以便取得最新定期檢修工單。 | stdout 是單一 JSON 物件，只有車組/車號、檢修級別、工作單、檢修日期四欄。 |

輸入車組/車號後，程式登入 MMIS，進入定期檢修工單的所有記錄，按錄製條件查詢所有分頁，依檢修日期選出一筆並列印 JSON。

## 功能需求

- 查詢條件固定為輸入的車組/車號、檢修單位「檢查室」、工作單狀態「工單結案,簽核中」。這是指定錄製中使用的範圍。
- 車組/車號僅去除前後空白；空白輸入直接報錯。數字輸入按完整數字段比對，例如 `701` 可查得 `EMU701`，但不會選到 `EMU1701`；含字母輸入須與顯示車號相同，忽略英文字母大小寫。
- 完整讀取每一頁並驗證分頁計數一致後，以有效的 `YYYY/MM/DD` 檢修日期選最新一筆。同日多筆以工作單號字典序最大者為準，確保結果固定。
- 無結果、日期無效、表格或分頁不完整時，以既有 JSON 錯誤格式及非零結束碼回報，不輸出半套結果。

## 資料與 API

- 指令：`python -m tools.mmis_development.query_latest_periodic_inspection_work_order <車組/車號>`。
- 成功輸出：`{"車組/車號":"EMU701","檢修級別":"2A","工作單":"115-2A-74357-001","檢修日期":"2026/10/15"}`。
- 失敗輸出沿用 development tool 的 `success=false`、`error`、`message` JSON。
- 資料模型與持久資料：無變更。

## 安全性與驗收

- 沿用 `.env`、`MMISSession` 和既有 Maximo event。不得把憑證、cookie、token、HAR 或 session 寫入輸出與版本庫。
- 驗收以錄製的 17 筆結果確認最新日期與四欄；測試空結果、跨頁、同日、錯誤頁及日期；實際唯讀查詢可在 MMIS 可連線時執行。
- CLI 無圖形畫面，無 mockup 或視覺驗證需求。
