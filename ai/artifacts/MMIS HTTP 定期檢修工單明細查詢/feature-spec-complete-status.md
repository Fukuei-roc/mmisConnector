# 功能規格書

## Metadata

- 功能：查詢完整定期檢修工單狀態。英文名稱：Query Complete Periodic Inspection Work Order Status。
- 負責人：專案使用者。
- 狀態：使用者於 2026-11-05 提出具體需求與錄製案例；已實作，待人工驗收。
- 風險等級：中。沿用唯讀 MMIS HTTPS session。

## 問題與目標

使用者輸入一筆定期檢修工作單主號，取得其所有子工單目前的狀態。每次命令只查一筆輸入，並在 stdout 印出一個 JSON 物件。

## 非目標

- 不批次查詢多個輸入工作單。
- 不修改 MMIS 工單或其狀態。
- 不進入各子工單明細頁，也不輸出完整檢修記錄。

## 使用者故事與驗收標準

| 故事 | 驗收標準 |
|---|---|
| 查詢主工單的全部子工單狀態 | `115-3A-75840` 回傳 3 筆，`115-2A-74886` 回傳 2 筆；每筆包含車組/車號、檢修級別、工作單、檢修單位、工作單狀態。 |

## 資料與 API

- 輸入：一個工作單主號，僅允許英數字與連字號，前後空白會去除。
- 命令：`python -m tools.mmis_development.query_complete_periodic_inspection_work_order_status <工作單>`。
- 輸出：`success`、`query_name`、`work_order`、`count`、`records`。`records` 是五欄物件陣列。
- 查詢：進入 `ZZ_PMWO`，切換「所有記錄」，設定「工作單」為輸入值、「母工單」為 `0`，送出篩選，讀完全部分頁。
- 驗證：每筆工作單須以主號加連字號開頭，尾碼為數字；母工單須為 `0`；拒絕重複與分頁不一致資料。
- 空結果：回傳成功、`count: 0` 與空陣列。查詢失敗以 JSON 錯誤與非零結束碼表示。

## 安全性與驗證

- 權限使用既有 MMIS 帳號；程式不儲存憑證、session、HAR 或回應全文。
- 用合成表格測試事件順序、分頁與錯誤路徑；再對兩筆指定工作單做即時唯讀查詢。
