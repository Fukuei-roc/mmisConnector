# 功能規格書

## Metadata

- 功能：查詢未送簽核的日檢工單
- 負責人：MMIS Connector
- 狀態：2026-11-03 增加執行中已派工工單的檢車室人員檢查與備註填寫。
- 風險等級：高，因查詢跨越 MMIS 身分驗證與網路邊界。

## 問題與目標

內部使用者需要取得符合條件的日檢工單，供後續檢視。工具進入「動力車日檢(1A)」後，先設定檢修段為新竹機務段並清空預設帶入的配屬段，再套用檢修日期早於台北當日、工作單狀態為執行中已派工、執行中未派工、完工待回報、工單初始、工單取消、工單取消核簽中、工單取消申請、工單結案、工單退回、檢修完成，並將結果存入 `data/daily_inspection_work_orders_not_submitted_for_approval.db`。不切換「所有記錄」。

## 範圍與非目標

- 輸出 14 欄。欄名依錄製畫面，其中畫面上的「逾期標註?」在 JSON 中命名為「逾期標註」且型別為布林值。
- 完整讀取預設清單的所有結果頁，核對每頁範圍、總筆數與工作單唯一性。
- 每次清單查詢成功後，在單一 SQLite 交易中清空舊資料並寫入本次結果。零筆結果會留下空資料表；清單查詢或快照寫入失敗時保留前次成功的資料。快照提交後若明細查詢失敗，保留本次快照但不填寫任何備註。
- 快照建立後，依資料庫順序逐筆查詢狀態為「執行中已派工」的 1A 工單明細。檢修記錄皆已回報，且檢車室檢查員與技術人員的 records 均為空時，將該筆 SQLite「備註欄」寫為「通知檢車室」。其他資料保持空白。
- 不修改 MMIS 資料，不新增正式 CLI 指令。
- 無 UI 變更，因此不適用畫面規格與 mockup 關卡。

## 資料與錯誤契約

- 輸入：無參數或 `--export-xlsx`；查詢日期取執行時 `Asia/Taipei` 當日。
- 加上 `--export-xlsx` 時，SQLite 快照成功後，讀取並核對完整快照筆數，只保留「備註欄」精確等於「通知檢車室」的資料，產生五欄 Excel：項次、車組/車號、工作單、車次、檢修日期。先篩選，再依檢修日期升序、車次 A 到 Z、車組/車號 A 到 Z 排序，最後由 1 起編項次。零筆符合時仍產生只有標題列的 Excel。
- Excel 輸出目錄取 `.env` 的 `UNCLOSED_AB_FAULT_NOTICES_XLSX_DIR`；檔名為 `檢車室未填檢修人員日檢工單_程式產生MMDD.xlsx`。同名檔存在時沿用既有匯出器的序號後綴，避免覆寫。
- Excel 欄寬依序為 5.7、11.8、17.9、6.5、14.5；所有列高（含標題列）固定為 15.5。字型、大小與對齊沿用既有 XLSX 工作表樣式。
- 成功時標準輸出以英文列印 `Status: SUCCESS`、`Records found: <count>`、`Vehicle room notifications: <count>`、`Database path: data/daily_inspection_work_orders_not_submitted_for_approval.db`。通知筆數為 SQLite「備註欄」等於「通知檢車室」的筆數，不列印逐筆工單資料。
- SQLite 資料表 `daily_inspection_work_orders_not_submitted_for_approval` 每筆包含檢修段、配屬段、車組/車號、檢修級別、工作單、車次、檢修單位、工作單狀態、處理人員、預計檢修(進廠)日、檢修日期、完工日期、階段核簽人、逾期標註，最右欄為備註欄。工作單為主鍵，逾期標註以 0/1 儲存，其餘欄位為文字。
- 明細查詢沿用同一個 MMIS session，核對返回的工作單號。任何明細查詢失敗時，本次備註更新不寫入，命令以失敗結束；已建立的 SQLite 快照保留。
- 查詢、欄位結構、分頁或資料庫寫入失敗時，以英文列印 `Status: FAILED`、`Records found: unavailable`、資料庫相對路徑及例外類別，結束碼為 1。不列印可能含敏感資訊的例外訊息。
- 透過既有 `MMISSession` 使用環境憑證；不在程式或產出物儲存憑證。

## 驗收標準

- 錄製資料可解析出 1 筆及全部 14 欄。
- 工作單狀態使用指定的十種值過濾；逐列拒絕不在清單內的狀態。
- 進入 1A 後清空配屬段預設值 `=新竹機務段`，並直接在預設清單過濾。
- SQLite 最右欄為備註欄；只有上述三條件全成立的「執行中已派工」工單填入「通知檢車室」。
- CLI 的 `Vehicle room notifications` 與本次 SQLite 快照中「通知檢車室」的筆數相同，零筆時顯示 `0`。
- 31 筆測試資料跨 2 頁完整返回，筆數與順序正確。
- 缺少下一頁、頁面範圍錯誤或重複工作單時拒絕成功輸出。
- 連續執行只保留最新一次完整查詢結果；零筆結果清空舊資料。
- 寫入失敗時回滾，前次成功結果不變。
- Live 唯讀查詢可產生 SQLite 資料庫，並以英文顯示執行狀態、筆數及路徑。
- `--export-xlsx` 成功時額外列印 Excel 路徑；檔案只含需通知檢車室的資料，欄位、排序、項次、欄寬與樣式符合上述契約。匯出失敗時回報失敗，已提交的 SQLite 快照保留。
