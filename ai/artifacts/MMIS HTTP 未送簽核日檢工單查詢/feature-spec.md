# 功能規格書

## Metadata

- 功能：查詢未送簽核的日檢工單
- 負責人：MMIS Connector
- 狀態：已實作。使用者於 2026-11-02 明確要求實作。
- 風險等級：高，因查詢跨越 MMIS 身分驗證與網路邊界。

## 問題與目標

內部使用者需要一次取得所有符合條件的日檢工單，供後續檢視。工具查詢「動力車日檢(1A)」的所有記錄，套用檢修段為新竹機務段、檢修日期早於台北當日、工作單狀態為執行中已派工三個條件，直接在標準輸出列印 JSON。

## 範圍與非目標

- 輸出 14 欄。欄名依錄製畫面，其中畫面上的「逾期標註?」在 JSON 中命名為「逾期標註」且型別為布林值。
- 完整讀取所有結果頁，核對每頁範圍、總筆數與工作單唯一性。
- 不產生查詢結果檔案，不修改 MMIS 資料，不新增正式 CLI 指令。
- 無 UI 變更，因此不適用畫面規格與 mockup 關卡。

## 資料與錯誤契約

- 輸入：無參數；查詢日期取執行時 `Asia/Taipei` 當日。
- 成功：`success`, `query_name`, `depot`, `before_inspection_date`, `status`, `count`, `records`。
- `records` 每筆包含檢修段、配屬段、車組/車號、檢修級別、工作單、車次、檢修單位、工作單狀態、處理人員、預計檢修(進廠)日、檢修日期、完工日期、階段核簽人、逾期標註。
- 查詢、欄位結構或分頁不完整時輸出錯誤 JSON，結束碼為 1。
- 透過既有 `MMISSession` 使用環境憑證；不在程式或產出物儲存憑證。

## 驗收標準

- 錄製資料可解析出 1 筆及全部 14 欄。
- 31 筆測試資料跨 2 頁完整返回，筆數與順序正確。
- 缺少下一頁、頁面範圍錯誤或重複工作單時拒絕成功輸出。
- Live 唯讀查詢可輸出有效 JSON，且不產生結果檔案。
